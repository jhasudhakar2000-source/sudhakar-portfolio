# Sudhakar Portfolio

Foundation for a cinematic video-editor portfolio built with Next.js 15, TypeScript, Tailwind CSS, GSAP, Framer Motion, React Three Fiber, and Lenis.

## Start locally

```bash
npm install
npm run dev
```

## Current scope

This initial phase contains the application architecture, responsive layout primitives, typed project data, SEO routes, and placeholder page sections. The final visual design, hero treatment, media, and animations are intentionally deferred.
